###############################
 [607] COMMON_APP_IMPORT_ERROR
###############################

*************
 Description
*************

A ServerApp, ClientApp or AgentApp failed to import a required module. This can happen
because a dependency is missing, or because a module from your app could not be found.

****************
 How to Resolve
****************

Check the error message to identify the missing module.

App module or file
==================

If the missing import refers to a module or ``.py`` file in your app, make sure that:

- the file is included in the app
- the import name is correct

Library dependency
==================

If the missing import refers to a library dependency, resolve it based on your
dependency installation setup.

If automatic runtime dependency installation is enabled, add the missing package to the
app's ``pyproject.toml`` dependencies and run the app again.

If automatic runtime dependency installation is disabled, install the missing package in
the Python environment where the ServerApp or ClientApp process runs. Alternatively,
consider enabling automatic runtime dependency installation. See :doc:`Install Flower
App dependencies at runtime <../how-to-install-app-dependencies-at-runtime>` for
details.
