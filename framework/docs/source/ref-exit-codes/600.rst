##############################
 [600] COMMON_ADDRESS_INVALID
##############################

*************
 Description
*************

The provided address is invalid and cannot be parsed. It must be a domain name, IPv4, or
IPv6 address with a port number, without a URL prefix such as ``http://`` or
``https://``.

****************
 How to Resolve
****************

Verify that the address is correctly formatted as one of the following:

- Domain name (e.g., ``api.flower.ai:443`` or ``example.com:8080``)
- IPv4 (e.g., ``192.168.1.1:9091``)
- IPv6 (e.g., ``[2001:0db8::1]:8000``)

For ``flower-supernode``, HTTPS is enabled by default. To use HTTP, pass ``--insecure``
instead of adding a URL prefix to ``--superlink``.
