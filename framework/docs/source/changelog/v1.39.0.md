### What's new?

- **Read Notion users, pages, properties, blocks, meeting notes, and databases** ([#8245](https://github.com/flwrlabs/flower/pull/8245), [#8252](https://github.com/flwrlabs/flower/pull/8252), [#8255](https://github.com/flwrlabs/flower/pull/8255), [#8266](https://github.com/flwrlabs/flower/pull/8266))

  The Notion connector now exposes read actions for users, page metadata and complete property values, individual blocks and their children, AI meeting notes, and database metadata with associated data source references. The actions map directly to Notion API endpoints, return native responses, and support the relevant filtering, sorting, and pagination options.

- **Add federation-wide connectors** ([#8210](https://github.com/flwrlabs/flower/pull/8210), [#8237](https://github.com/flwrlabs/flower/pull/8237), [#8239](https://github.com/flwrlabs/flower/pull/8239), [#8240](https://github.com/flwrlabs/flower/pull/8240), [#8265](https://github.com/flwrlabs/flower/pull/8265))

  Connector storage, OAuth sessions, APIs, and task metadata now carry federation scope, allowing members to connect, list, disconnect, and use connector-backed runs in federations. Federations can now keep multiple connections to the same provider, and select one connection of each provider per run.

- **Run sparse federated learning experiments with SSFL** ([#7900](https://github.com/flwrlabs/flower/pull/7900))

  The new SSFL baseline implements static sparse federated learning with the Message API, client-side saliency scoring, global mask aggregation, and sample-weighted sparse FedAvg. It includes ResNet-18 experiments for CIFAR-10 and CIFAR-100, paper-scale configurations, communication accounting, and reproduction guidance.

- **Get faster agent responses** ([#8225](https://github.com/flwrlabs/flower/pull/8225), [#8226](https://github.com/flwrlabs/flower/pull/8226), [#8227](https://github.com/flwrlabs/flower/pull/8227), [#8231](https://github.com/flwrlabs/flower/pull/8231), [#8232](https://github.com/flwrlabs/flower/pull/8232), [#8233](https://github.com/flwrlabs/flower/pull/8233), [#8238](https://github.com/flwrlabs/flower/pull/8238))

- **General improvements** ([#8221](https://github.com/flwrlabs/flower/pull/8221), [#8229](https://github.com/flwrlabs/flower/pull/8229), [#8230](https://github.com/flwrlabs/flower/pull/8230), [#8234](https://github.com/flwrlabs/flower/pull/8234), [#8235](https://github.com/flwrlabs/flower/pull/8235), [#8242](https://github.com/flwrlabs/flower/pull/8242), [#8243](https://github.com/flwrlabs/flower/pull/8243), [#8244](https://github.com/flwrlabs/flower/pull/8244), [#8249](https://github.com/flwrlabs/flower/pull/8249), [#8253](https://github.com/flwrlabs/flower/pull/8253), [#8254](https://github.com/flwrlabs/flower/pull/8254), [#8256](https://github.com/flwrlabs/flower/pull/8256), [#8258](https://github.com/flwrlabs/flower/pull/8258), [#8259](https://github.com/flwrlabs/flower/pull/8259), [#8260](https://github.com/flwrlabs/flower/pull/8260), [#8261](https://github.com/flwrlabs/flower/pull/8261), [#8268](https://github.com/flwrlabs/flower/pull/8268), [#8270](https://github.com/flwrlabs/flower/pull/8270))
