- **Improve agent runtime infrastructure** ([#8444](https://github.com/flwrlabs/flower/pull/8444), [#8453](https://github.com/flwrlabs/flower/pull/8453), [#8477](https://github.com/flwrlabs/flower/pull/8477), [#8481](https://github.com/flwrlabs/flower/pull/8481), [#8484](https://github.com/flwrlabs/flower/pull/8484), [#8485](https://github.com/flwrlabs/flower/pull/8485), [#8494](https://github.com/flwrlabs/flower/pull/8494), [#8498](https://github.com/flwrlabs/flower/pull/8498), [#8500](https://github.com/flwrlabs/flower/pull/8500), [#8507](https://github.com/flwrlabs/flower/pull/8507), [#8511](https://github.com/flwrlabs/flower/pull/8511), [#8512](https://github.com/flwrlabs/flower/pull/8512), [#8517](https://github.com/flwrlabs/flower/pull/8517), [#8521](https://github.com/flwrlabs/flower/pull/8521), [#8523](https://github.com/flwrlabs/flower/pull/8523), [#8525](https://github.com/flwrlabs/flower/pull/8525), [#8527](https://github.com/flwrlabs/flower/pull/8527), [#8528](https://github.com/flwrlabs/flower/pull/8528), [#8532](https://github.com/flwrlabs/flower/pull/8532), [#8533](https://github.com/flwrlabs/flower/pull/8533), [#8534](https://github.com/flwrlabs/flower/pull/8534), [#8536](https://github.com/flwrlabs/flower/pull/8536), [#8545](https://github.com/flwrlabs/flower/pull/8545), [#8546](https://github.com/flwrlabs/flower/pull/8546), [#8547](https://github.com/flwrlabs/flower/pull/8547), [#8548](https://github.com/flwrlabs/flower/pull/8548), [#8550](https://github.com/flwrlabs/flower/pull/8550), [#8551](https://github.com/flwrlabs/flower/pull/8551), [#8552](https://github.com/flwrlabs/flower/pull/8552), [#8563](https://github.com/flwrlabs/flower/pull/8563))

  AgentApps can use compacted context from earlier runs and access tools from multiple connected accounts. Experimental file storage also lets AgentApps read and write files scoped to the current agent.

- **Start work faster on prewarmed workers** ([#8482](https://github.com/flwrlabs/flower/pull/8482), [#8487](https://github.com/flwrlabs/flower/pull/8487), [#8490](https://github.com/flwrlabs/flower/pull/8490))

  Prewarmed AgentApp and connector workers now start handling tasks sooner because the handoff loads fewer Python modules. In local Kubernetes benchmarks, median task handoff time fell from 480 ms to 101 ms.

- **General improvements** ([#8469](https://github.com/flwrlabs/flower/pull/8469), [#8480](https://github.com/flwrlabs/flower/pull/8480), [#8483](https://github.com/flwrlabs/flower/pull/8483), [#8489](https://github.com/flwrlabs/flower/pull/8489), [#8497](https://github.com/flwrlabs/flower/pull/8497), [#8503](https://github.com/flwrlabs/flower/pull/8503), [#8504](https://github.com/flwrlabs/flower/pull/8504), [#8505](https://github.com/flwrlabs/flower/pull/8505), [#8506](https://github.com/flwrlabs/flower/pull/8506), [#8508](https://github.com/flwrlabs/flower/pull/8508), [#8509](https://github.com/flwrlabs/flower/pull/8509), [#8513](https://github.com/flwrlabs/flower/pull/8513), [#8514](https://github.com/flwrlabs/flower/pull/8514), [#8516](https://github.com/flwrlabs/flower/pull/8516), [#8520](https://github.com/flwrlabs/flower/pull/8520), [#8522](https://github.com/flwrlabs/flower/pull/8522), [#8530](https://github.com/flwrlabs/flower/pull/8530), [#8539](https://github.com/flwrlabs/flower/pull/8539), [#8554](https://github.com/flwrlabs/flower/pull/8554), [#8555](https://github.com/flwrlabs/flower/pull/8555), [#8556](https://github.com/flwrlabs/flower/pull/8556), [#8558](https://github.com/flwrlabs/flower/pull/8558))
