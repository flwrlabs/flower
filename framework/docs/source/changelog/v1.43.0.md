### What's new?

- **Stop strategies before all rounds complete** ([#8401](https://github.com/flwrlabs/flower/pull/8401))

  Pass a `should_stop(server_round, result)` callback to `Strategy.start()` to stop an FL run after any completed round and return the current model and collected metrics through the normal exit path.

- **Use HTTP for Fleet and Control APIs** ([#8458](https://github.com/flwrlabs/flower/pull/8458), [#8462](https://github.com/flwrlabs/flower/pull/8462), [#8463](https://github.com/flwrlabs/flower/pull/8463), [#8464](https://github.com/flwrlabs/flower/pull/8464), [#8467](https://github.com/flwrlabs/flower/pull/8467), [#8468](https://github.com/flwrlabs/flower/pull/8468), [#8475](https://github.com/flwrlabs/flower/pull/8475))

  SuperLink now serves the Fleet and Control APIs over HTTP only. Their legacy gRPC services and the optional gRPC health service have been removed, remaining compatibility gRPC code lives under `flwr.compat`, and deprecated transport options no longer configure active services.

- **Reduce Agent response latency** ([#8425](https://github.com/flwrlabs/flower/pull/8425), [#8431](https://github.com/flwrlabs/flower/pull/8431), [#8432](https://github.com/flwrlabs/flower/pull/8432), [#8437](https://github.com/flwrlabs/flower/pull/8437), [#8449](https://github.com/flwrlabs/flower/pull/8449))

  Runtime Responses now call inference endpoints directly, and Agent warm pools are maintained in the background. The obsolete Model worker and its message transport are removed, while the AgentApp API remains unchanged.

- **Create and list persistent Agents (experimental)** ([#8430](https://github.com/flwrlabs/flower/pull/8430), [#8435](https://github.com/flwrlabs/flower/pull/8435), [#8439](https://github.com/flwrlabs/flower/pull/8439), [#8440](https://github.com/flwrlabs/flower/pull/8440), [#8441](https://github.com/flwrlabs/flower/pull/8441), [#8443](https://github.com/flwrlabs/flower/pull/8443), [#8445](https://github.com/flwrlabs/flower/pull/8445))

  The Control API now supports creating and listing persistent Agents owned by the authenticated account. CoreState also stores conversations and messages, laying the groundwork for conversation APIs.

- **General improvements** ([#8410](https://github.com/flwrlabs/flower/pull/8410), [#8411](https://github.com/flwrlabs/flower/pull/8411), [#8413](https://github.com/flwrlabs/flower/pull/8413), [#8414](https://github.com/flwrlabs/flower/pull/8414), [#8421](https://github.com/flwrlabs/flower/pull/8421), [#8422](https://github.com/flwrlabs/flower/pull/8422), [#8428](https://github.com/flwrlabs/flower/pull/8428), [#8436](https://github.com/flwrlabs/flower/pull/8436), [#8438](https://github.com/flwrlabs/flower/pull/8438), [#8447](https://github.com/flwrlabs/flower/pull/8447), [#8448](https://github.com/flwrlabs/flower/pull/8448), [#8455](https://github.com/flwrlabs/flower/pull/8455), [#8460](https://github.com/flwrlabs/flower/pull/8460), [#8461](https://github.com/flwrlabs/flower/pull/8461), [#8465](https://github.com/flwrlabs/flower/pull/8465), [#8466](https://github.com/flwrlabs/flower/pull/8466), [#8470](https://github.com/flwrlabs/flower/pull/8470), [#8471](https://github.com/flwrlabs/flower/pull/8471), [#8472](https://github.com/flwrlabs/flower/pull/8472))

  As always, many parts of the Flower framework and quality infrastructure were improved and updated.

### Incompatible changes

- **Handle unavailable nodes explicitly in strategies** ([#8385](https://github.com/flwrlabs/flower/pull/8385), [#8409](https://github.com/flwrlabs/flower/pull/8409), [#8415](https://github.com/flwrlabs/flower/pull/8415), [#8426](https://github.com/flwrlabs/flower/pull/8426), [#8429](https://github.com/flwrlabs/flower/pull/8429))

  The messaging system has been reworked for improved stability and flexibility. SuperLink no longer generates automatic error replies, so custom strategies relying on them must handle unavailable nodes and missing replies explicitly. The standard `Strategy.start()` loop handles unavailable nodes automatically.
