### What's new?

- **Use GitHub, Notion, Slack, Attio, and Google connectors through MCP** ([#8328](https://github.com/flwrlabs/flower/pull/8328), [#8339](https://github.com/flwrlabs/flower/pull/8339), [#8343](https://github.com/flwrlabs/flower/pull/8343), [#8362](https://github.com/flwrlabs/flower/pull/8362), [#8382](https://github.com/flwrlabs/flower/pull/8382))

  GitHub, Notion, Slack, and Attio connectors now integrate through MCP, with tools discovered dynamically from each connected account. New Google Drive, Gmail, and Google Calendar connectors use Google's remote MCP servers with OAuth/PKCE and token refresh.

- **Store and reuse compacted AgentApp contexts (experimental)** ([#8350](https://github.com/flwrlabs/flower/pull/8350), [#8363](https://github.com/flwrlabs/flower/pull/8363), [#8364](https://github.com/flwrlabs/flower/pull/8364), [#8367](https://github.com/flwrlabs/flower/pull/8367), [#8370](https://github.com/flwrlabs/flower/pull/8370), [#8371](https://github.com/flwrlabs/flower/pull/8371), [#8376](https://github.com/flwrlabs/flower/pull/8376), [#8377](https://github.com/flwrlabs/flower/pull/8377), [#8380](https://github.com/flwrlabs/flower/pull/8380))

  AgentApps can now filter run-series events and read or store compacted contexts through `AgentSession.events`. Compacted contexts are persisted per run series and exposed through authenticated Runtime API endpoints with newest-first paginated reads.

- **Lay the groundwork for faster AgentApp responses** ([#8375](https://github.com/flwrlabs/flower/pull/8375), [#8388](https://github.com/flwrlabs/flower/pull/8388))

- **General improvements** ([#8341](https://github.com/flwrlabs/flower/pull/8341), [#8345](https://github.com/flwrlabs/flower/pull/8345), [#8349](https://github.com/flwrlabs/flower/pull/8349), [#8356](https://github.com/flwrlabs/flower/pull/8356), [#8357](https://github.com/flwrlabs/flower/pull/8357), [#8358](https://github.com/flwrlabs/flower/pull/8358), [#8359](https://github.com/flwrlabs/flower/pull/8359), [#8360](https://github.com/flwrlabs/flower/pull/8360), [#8361](https://github.com/flwrlabs/flower/pull/8361), [#8365](https://github.com/flwrlabs/flower/pull/8365), [#8366](https://github.com/flwrlabs/flower/pull/8366), [#8372](https://github.com/flwrlabs/flower/pull/8372), [#8373](https://github.com/flwrlabs/flower/pull/8373), [#8374](https://github.com/flwrlabs/flower/pull/8374), [#8378](https://github.com/flwrlabs/flower/pull/8378), [#8384](https://github.com/flwrlabs/flower/pull/8384), [#8387](https://github.com/flwrlabs/flower/pull/8387), [#8389](https://github.com/flwrlabs/flower/pull/8389), [#8394](https://github.com/flwrlabs/flower/pull/8394))

  As always, many parts of the Flower framework and quality infrastructure were improved and updated.
