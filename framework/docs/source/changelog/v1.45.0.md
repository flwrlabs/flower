### What's new?

- **Apply differential privacy operations only to floating-point arrays** ([#8381](https://github.com/flwrlabs/flower/pull/8381))

  Differential privacy norm calculation, clipping, and noise addition now ignore non-floating model state such as BatchNorm tracking buffers, preventing casting errors and unintended changes to integer arrays.

- **Track active Agent runs in clients** ([#8549](https://github.com/flwrlabs/flower/pull/8549), [#8572](https://github.com/flwrlabs/flower/pull/8572))

  Clients can restore unfinished Agent runs from the bootstrap response and receive `run.created` and `run.finished` events, including failure, cancellation, and heartbeat-expiry outcomes.

- **Manage persistent Agents and their default Spaces (experimental)** ([#8560](https://github.com/flwrlabs/flower/pull/8560), [#8561](https://github.com/flwrlabs/flower/pull/8561), [#8562](https://github.com/flwrlabs/flower/pull/8562), [#8564](https://github.com/flwrlabs/flower/pull/8564), [#8566](https://github.com/flwrlabs/flower/pull/8566), [#8568](https://github.com/flwrlabs/flower/pull/8568), [#8570](https://github.com/flwrlabs/flower/pull/8570), [#8585](https://github.com/flwrlabs/flower/pull/8585), [#8589](https://github.com/flwrlabs/flower/pull/8589), [#8590](https://github.com/flwrlabs/flower/pull/8590), [#8591](https://github.com/flwrlabs/flower/pull/8591), [#8598](https://github.com/flwrlabs/flower/pull/8598), [#8606](https://github.com/flwrlabs/flower/pull/8606), [#8609](https://github.com/flwrlabs/flower/pull/8609))

  Persistent Agents now have an owner-scoped default Space and versioned, editable configuration, including avatar and color identifiers. The Control API supports conflict-safe updates and history-preserving deletion, while Space listings expose the latest user message. The database migration resets existing Agents and their dependent data; retained runs have their Agent references cleared.

- **Use typed Space items in AgentApps** ([#8579](https://github.com/flwrlabs/flower/pull/8579), [#8580](https://github.com/flwrlabs/flower/pull/8580), [#8581](https://github.com/flwrlabs/flower/pull/8581), [#8583](https://github.com/flwrlabs/flower/pull/8583), [#8586](https://github.com/flwrlabs/flower/pull/8586), [#8587](https://github.com/flwrlabs/flower/pull/8587), [#8595](https://github.com/flwrlabs/flower/pull/8595), [#8597](https://github.com/flwrlabs/flower/pull/8597), [#8600](https://github.com/flwrlabs/flower/pull/8600), [#8605](https://github.com/flwrlabs/flower/pull/8605), [#8610](https://github.com/flwrlabs/flower/pull/8610), [#8612](https://github.com/flwrlabs/flower/pull/8612), [#8614](https://github.com/flwrlabs/flower/pull/8614))

  AgentApps can now send and page through typed `SpaceItem`s, including unread-only reads tracked per Space participant. The ordered stream supports messages and automation inputs and lets runs record their triggering item, while existing Space message methods and the model-facing `send_space_message` tool remain available.

- **General improvements** ([#8565](https://github.com/flwrlabs/flower/pull/8565), [#8567](https://github.com/flwrlabs/flower/pull/8567), [#8569](https://github.com/flwrlabs/flower/pull/8569), [#8571](https://github.com/flwrlabs/flower/pull/8571), [#8574](https://github.com/flwrlabs/flower/pull/8574), [#8575](https://github.com/flwrlabs/flower/pull/8575), [#8578](https://github.com/flwrlabs/flower/pull/8578), [#8584](https://github.com/flwrlabs/flower/pull/8584), [#8592](https://github.com/flwrlabs/flower/pull/8592), [#8593](https://github.com/flwrlabs/flower/pull/8593), [#8599](https://github.com/flwrlabs/flower/pull/8599), [#8607](https://github.com/flwrlabs/flower/pull/8607), [#8608](https://github.com/flwrlabs/flower/pull/8608))

  As always, many parts of the Flower framework and quality infrastructure were improved and updated.
