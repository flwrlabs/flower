### What's new?

- **Apply differential privacy operations only to floating-point arrays** ([#8381](https://github.com/flwrlabs/flower/pull/8381))

  Differential privacy norm calculation, clipping, and noise addition now ignore non-floating model state such as BatchNorm tracking buffers, preventing casting errors and unintended changes to integer arrays.

- **Improve the Agent runtime** ([#8549](https://github.com/flwrlabs/flower/pull/8549), [#8560](https://github.com/flwrlabs/flower/pull/8560), [#8561](https://github.com/flwrlabs/flower/pull/8561), [#8562](https://github.com/flwrlabs/flower/pull/8562), [#8564](https://github.com/flwrlabs/flower/pull/8564), [#8566](https://github.com/flwrlabs/flower/pull/8566), [#8568](https://github.com/flwrlabs/flower/pull/8568), [#8570](https://github.com/flwrlabs/flower/pull/8570), [#8572](https://github.com/flwrlabs/flower/pull/8572), [#8579](https://github.com/flwrlabs/flower/pull/8579), [#8580](https://github.com/flwrlabs/flower/pull/8580), [#8581](https://github.com/flwrlabs/flower/pull/8581), [#8583](https://github.com/flwrlabs/flower/pull/8583), [#8585](https://github.com/flwrlabs/flower/pull/8585), [#8586](https://github.com/flwrlabs/flower/pull/8586), [#8587](https://github.com/flwrlabs/flower/pull/8587), [#8589](https://github.com/flwrlabs/flower/pull/8589), [#8590](https://github.com/flwrlabs/flower/pull/8590), [#8591](https://github.com/flwrlabs/flower/pull/8591), [#8595](https://github.com/flwrlabs/flower/pull/8595), [#8597](https://github.com/flwrlabs/flower/pull/8597), [#8598](https://github.com/flwrlabs/flower/pull/8598), [#8600](https://github.com/flwrlabs/flower/pull/8600), [#8605](https://github.com/flwrlabs/flower/pull/8605), [#8606](https://github.com/flwrlabs/flower/pull/8606), [#8609](https://github.com/flwrlabs/flower/pull/8609), [#8610](https://github.com/flwrlabs/flower/pull/8610), [#8612](https://github.com/flwrlabs/flower/pull/8612), [#8614](https://github.com/flwrlabs/flower/pull/8614))
