### What's new?

- **Choose an agent in `flwr chat` (experimental)** ([#7787](https://github.com/flwrlabs/flower/pull/7787))

  Use the new `@` selector to choose an available agent for subsequent chat runs. The CLI fetches the choices from the SuperLink and continues to use Flower Agent by default.

- **Connect AgentApps to Slack, Notion, GitHub, and Attio** ([#7600](https://github.com/flwrlabs/flower/pull/7600), [#7738](https://github.com/flwrlabs/flower/pull/7738), [#7749](https://github.com/flwrlabs/flower/pull/7749), [#7752](https://github.com/flwrlabs/flower/pull/7752), [#7756](https://github.com/flwrlabs/flower/pull/7756), [#7784](https://github.com/flwrlabs/flower/pull/7784), [#7786](https://github.com/flwrlabs/flower/pull/7786), [#7792](https://github.com/flwrlabs/flower/pull/7792))

  AgentApps can now use OAuth connectors for Slack, Notion, GitHub, and Attio. Shared OAuth configuration and runtime tool expansion provide consistent authentication and connector availability across these integrations.

- **Improve database reliability across SQLite and PostgreSQL** ([#7758](https://github.com/flwrlabs/flower/pull/7758), [#7768](https://github.com/flwrlabs/flower/pull/7768), [#7769](https://github.com/flwrlabs/flower/pull/7769), [#7771](https://github.com/flwrlabs/flower/pull/7771), [#7772](https://github.com/flwrlabs/flower/pull/7772), [#7773](https://github.com/flwrlabs/flower/pull/7773), [#7775](https://github.com/flwrlabs/flower/pull/7775), [#7782](https://github.com/flwrlabs/flower/pull/7782), [#7785](https://github.com/flwrlabs/flower/pull/7785), [#7799](https://github.com/flwrlabs/flower/pull/7799), [#7803](https://github.com/flwrlabs/flower/pull/7803), [#7808](https://github.com/flwrlabs/flower/pull/7808), [#7812](https://github.com/flwrlabs/flower/pull/7812), [#7813](https://github.com/flwrlabs/flower/pull/7813), [#7814](https://github.com/flwrlabs/flower/pull/7814), [#7815](https://github.com/flwrlabs/flower/pull/7815), [#7817](https://github.com/flwrlabs/flower/pull/7817), [#7818](https://github.com/flwrlabs/flower/pull/7818), [#7831](https://github.com/flwrlabs/flower/pull/7831), [#7832](https://github.com/flwrlabs/flower/pull/7832), [#7833](https://github.com/flwrlabs/flower/pull/7833), [#7840](https://github.com/flwrlabs/flower/pull/7840), [#7844](https://github.com/flwrlabs/flower/pull/7844))

  PostgreSQL-backed deployments can now dispatch automations correctly, and existing SQLite automation timestamps are normalized during upgrades. `CoreState`, `LinkState`, and `ObjectStore` now standardize on declarative SQLAlchemy models and model-backed reads and writes, improving consistency across database backends while preserving atomic lifecycle transitions.

- **Configure and authenticate the Control API consistently** ([#7789](https://github.com/flwrlabs/flower/pull/7789), [#7791](https://github.com/flwrlabs/flower/pull/7791), [#7796](https://github.com/flwrlabs/flower/pull/7796), [#7797](https://github.com/flwrlabs/flower/pull/7797), [#7839](https://github.com/flwrlabs/flower/pull/7839), [#7845](https://github.com/flwrlabs/flower/pull/7845), [#7879](https://github.com/flwrlabs/flower/pull/7879), [#7887](https://github.com/flwrlabs/flower/pull/7887))

  Control API OIDC enablement now uses `FLWR_OIDC_ENABLED`, while HTTP authentication uses standard Bearer-token handling and FastAPI error responses. Obsolete authentication configuration, endpoints, and authorization paths have been removed.

- **Automate Framework minor releases** ([#7829](https://github.com/flwrlabs/flower/pull/7829), [#7837](https://github.com/flwrlabs/flower/pull/7837), [#7848](https://github.com/flwrlabs/flower/pull/7848), [#7855](https://github.com/flwrlabs/flower/pull/7855), [#7856](https://github.com/flwrlabs/flower/pull/7856), [#7861](https://github.com/flwrlabs/flower/pull/7861), [#7863](https://github.com/flwrlabs/flower/pull/7863), [#7877](https://github.com/flwrlabs/flower/pull/7877), [#7878](https://github.com/flwrlabs/flower/pull/7878), [#7880](https://github.com/flwrlabs/flower/pull/7880), [#7883](https://github.com/flwrlabs/flower/pull/7883), [#7885](https://github.com/flwrlabs/flower/pull/7885), [#7889](https://github.com/flwrlabs/flower/pull/7889), [#7893](https://github.com/flwrlabs/flower/pull/7893))

  Rerunnable workflows now prepare, validate, and finalize Framework minor releases from a fixed `main` commit while preserving human changelog edits. Deterministic version updates, commit-addressed and reusable artifacts, and retry-safe publication reduce release overhead and support more frequent Flower releases.

- **Unify the Runtime API for SuperLink and SuperNode** ([#7764](https://github.com/flwrlabs/flower/pull/7764), [#7777](https://github.com/flwrlabs/flower/pull/7777), [#7783](https://github.com/flwrlabs/flower/pull/7783), [#7793](https://github.com/flwrlabs/flower/pull/7793), [#7794](https://github.com/flwrlabs/flower/pull/7794))

  `ServerAppIo` and `ClientAppIo` now share the same `Runtime` gRPC service contract and terminology across SuperLink and SuperNode. Existing CLI flags and configuration names remain unchanged for compatibility.

- **Prepare to migrate the Runtime API from gRPC to HTTP** ([#7800](https://github.com/flwrlabs/flower/pull/7800), [#7801](https://github.com/flwrlabs/flower/pull/7801), [#7804](https://github.com/flwrlabs/flower/pull/7804), [#7805](https://github.com/flwrlabs/flower/pull/7805), [#7807](https://github.com/flwrlabs/flower/pull/7807), [#7809](https://github.com/flwrlabs/flower/pull/7809), [#7820](https://github.com/flwrlabs/flower/pull/7820), [#7830](https://github.com/flwrlabs/flower/pull/7830), [#7834](https://github.com/flwrlabs/flower/pull/7834), [#7847](https://github.com/flwrlabs/flower/pull/7847), [#7849](https://github.com/flwrlabs/flower/pull/7849), [#7851](https://github.com/flwrlabs/flower/pull/7851), [#7854](https://github.com/flwrlabs/flower/pull/7854), [#7860](https://github.com/flwrlabs/flower/pull/7860), [#7864](https://github.com/flwrlabs/flower/pull/7864), [#7865](https://github.com/flwrlabs/flower/pull/7865), [#7867](https://github.com/flwrlabs/flower/pull/7867), [#7869](https://github.com/flwrlabs/flower/pull/7869), [#7876](https://github.com/flwrlabs/flower/pull/7876), [#7881](https://github.com/flwrlabs/flower/pull/7881), [#7886](https://github.com/flwrlabs/flower/pull/7886), [#7894](https://github.com/flwrlabs/flower/pull/7894))

  Flower is preparing to replace the Runtime API's gRPC transport with HTTP. This release adds transport-neutral handlers, FastAPI routes for SuperLink and SuperNode, and `httpx`-based clients while retaining the existing gRPC path during the transition.

- **Expose federation capabilities and prepare AgentApp discovery** ([#7838](https://github.com/flwrlabs/flower/pull/7838), [#7868](https://github.com/flwrlabs/flower/pull/7868), [#7871](https://github.com/flwrlabs/flower/pull/7871))

- **General improvements** ([#7755](https://github.com/flwrlabs/flower/pull/7755), [#7776](https://github.com/flwrlabs/flower/pull/7776), [#7781](https://github.com/flwrlabs/flower/pull/7781), [#7795](https://github.com/flwrlabs/flower/pull/7795), [#7802](https://github.com/flwrlabs/flower/pull/7802), [#7810](https://github.com/flwrlabs/flower/pull/7810), [#7822](https://github.com/flwrlabs/flower/pull/7822), [#7823](https://github.com/flwrlabs/flower/pull/7823), [#7824](https://github.com/flwrlabs/flower/pull/7824), [#7825](https://github.com/flwrlabs/flower/pull/7825), [#7826](https://github.com/flwrlabs/flower/pull/7826), [#7828](https://github.com/flwrlabs/flower/pull/7828), [#7857](https://github.com/flwrlabs/flower/pull/7857), [#7858](https://github.com/flwrlabs/flower/pull/7858), [#7862](https://github.com/flwrlabs/flower/pull/7862), [#7870](https://github.com/flwrlabs/flower/pull/7870), [#7873](https://github.com/flwrlabs/flower/pull/7873))

### Incompatible changes

- **Remove Flower Intelligence** ([#7778](https://github.com/flwrlabs/flower/pull/7778))

  With the introduction of **Flower Agents**, we are retiring Flower Intelligence. Flower Intelligence is no longer part of this repository; its Kotlin, Swift, and TypeScript SDKs, examples, documentation, and release tooling have been removed.
