Enterprise
==========

Flower Labs works with organizations that want to evaluate, deploy, adapt, or
integrate Flower models, including Endeavor 1.0 and Lizzy.

Work with us
------------

To request Enterprise support for Endeavor 1.0 or Lizzy, please use this form to
`contact Flower <https://flowerlabs.typeform.com/to/oSxsEvgq>`_.

Enterprise work can include:

- confidential evaluations on domain-specific prompts, policies, and workflows
- access planning, integration, and deployment guidance for Flower-managed and
  private Endeavor deployments
- GPU serving, local inference, and quantized deployment guidance for models
  that publish compatible artifacts
- model adaptation for tone, terminology, retrieval, and task performance
- safety, monitoring, and quality review for production use
- integration with existing applications, data systems, and governance
  processes

Typical engagements
-------------------

.. list-table::
   :header-rows: 1

   * - Need
     - Support
   * - Evaluate a Flower model for an internal use case
     - Benchmark design, test prompts, risk review, and deployment
       recommendations.
   * - Deploy Lizzy in production, or plan a supported Endeavor 1.0 deployment
     - Runtime selection, serving architecture, performance tuning, and
       operational review.
   * - Adapt the model to a domain
     - Data review, evaluation design, preference tuning, and release
       validation.
   * - Run local or confidential inference
     - GGUF, vLLM, and Transformers deployment guidance with appropriate
       monitoring and access controls.
